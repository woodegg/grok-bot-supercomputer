The contributor name, contact address, GitHub account and canonical repository
URL are intentionally public project information. Deployment accounts, topology,
identities, credentials and private operator records are excluded.

To contribute, follow AGENTS.md, explain the problem and proposed behavior, and
report relevant validation. Keep rootfs, runtime state, logs and credentials
outside Git. Configure your own Git author identity before committing changes.
